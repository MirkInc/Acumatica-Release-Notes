# Rental360 Release Notes

Comparison: `260302` to `260331`  
Package build: `25.201.0213.60331`

## Features Overview

The 260331 package updates Rental360 from 260302 to 260331. This note documents the sequential changes from the immediately previous package.

- Adds missing and damaged rental return processing so teams can review exceptions and create billing follow-up from one screen.
- Adds Rental360 feature controls for equipment management, rental management, add-on charges, and change orders.
- Adds owner, operator, project, and job-site tracking for rental orders or equipment records.
- Adds rental posting account and subaccount controls for inventory posting classes.
- Updates rental cycle and billing logic for recurring, return, and off-rent billing support.
- Updates work order behavior and related Rental360 work-order screens.
