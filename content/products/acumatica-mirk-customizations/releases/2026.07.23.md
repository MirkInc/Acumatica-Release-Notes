# Acumatica ~ MIRK.Customizations Release Notes

Comparison: `2026.06.12 to 2026.07.23`  
Build: `25.201.0213`

## Features Overview

The 2026.07.23 package updates MIRK.Customizations from 2026.06.12 to 2026.07.23.

### Employee Labor Calendar

- Adds a new employee-focused weekly labor calendar so users can review work order labor by day and time.
- Defaults the calendar to the current employee and keeps the employee filter locked, giving each user a focused schedule view.
- Adds previous week, current week, next week, refresh, and cancel controls for faster schedule navigation.
- Allows users to open the related work order from a calendar event.

### Tax Write-Off Support

- Adds a tax write-off workflow for invoices that are open or closed.
- Creates a credit memo workflow that offsets taxable lines and converts them to configured exempt tax categories.
- Adds a configurable summary item so the printed credit memo can show a clean tax write-off summary line.
- Adds setup support for mapping original tax categories to exempt tax categories.

### Screen and Usability Updates

- Updates the main MIRK setup screen to include the new tax write-off and tax-to-exempt configuration areas.
- Updates the existing labor calendar screen and supporting work order screens to carry more schedule and work order context.
- Adds work order import support for MIRK work order workflows.
- Cleans up equipment handling tied to purchase, registration, and setup carry-forward behavior.
- Refines commission and cash conversion internals carried forward from the previous package.

## Features Removed or Altered

No package files were removed.

The following behavior was altered:

- Tax-exempt invoice handling now includes a `Write Off Taxes` correction action for eligible invoices.
- Tax write-off processing depends on configured tax-category conversion records and a configured tax write-off summary non-stock item.
- The employee labor calendar shows only the current user's employee schedule instead of acting as an unrestricted labor calendar.
- Several processing and maintenance classes had activation checks simplified so feature availability relies more directly on setup-controlled behavior.

#### Code-Level Changes

- Adds `MIRK9001`, a Bryntum SchedulerPro-based employee labor calendar screen backed by `MIRKWorkOrderLaborCalendarEmployeeGraph`.
- Adds calendar resource/event view models for weekly employee schedule rendering.
- Adds event click handling that loads the source work order keys and opens the related work order.
- Adds tax write-off actions on invoice entry graph extensions for eligible open or closed invoices.
- Adds line conversion logic that creates offsetting positive and negative lines, converts the exempt side to a configured tax category, and hides detail lines from print where appropriate.
- Adds a tax write-off summary line using the setup-defined inventory item.
- Adds `MIRKTaxToExemptConversion` for mapping taxable categories to exempt categories.
- Adds setup accessors for tax write-off summary inventory and tax-to-exempt conversion records.
- Adds work order import support through `MIRKNVRTWorkOrderMaintGraphExt_Import`.
- Moves employee labor calendar data shaping into dedicated employee calendar DAC and graph classes.
- Adds AP adjustment cash-converted tracking and keeps cash conversion refactors aligned with the AP/AR conversion process.
- Removes or simplifies `IsActive()` checks across multiple maintenance and processing classes.
- Updates labor calendar data objects with additional work order, employee, time, and display context.
- Updates invoice tax-exempt and rental-tax graph extensions for SO invoice and AR invoice workflows.
- Cleans up equipment setup handling by removing obsolete carry-forward logic from `MIRKCustomizationsSetup` and shifting current behavior into runtime graph logic.
