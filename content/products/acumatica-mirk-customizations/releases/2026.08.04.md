# Acumatica ~ MIRK.Customizations Release Notes

Comparison: `2026.07.23 to 2026.08.04`  
Build: `25.201.0213`

## Features Overview

The 2026.08.04 package updates MIRK.Customizations from 2026.07.23 to 2026.08.04.

### Purchasing Defaults

- Purchase orders and purchase lines now default the site based on the selected branch when possible.
- This reduces manual warehouse/site entry and helps PO documents align with branch-level setup.
- The defaulting logic includes additional null checks so incomplete branch or location data is handled more safely.

### Cash Conversion and Payment Handling

- Improves cash conversion handling for AR payment charge lines and related GL batch processing.
- Adds clearer validation messages for tax and cash conversion scenarios.
- Refines eligibility checks so users receive more specific feedback when a record cannot be processed.

### Tax Write-Off and Invoice Corrections

- Sets tax write-off credit memo dates to the current Acumatica business date.
- Refines invoice tax write-off handling for rental-tax and tax-exempt invoice workflows.
- Keeps the tax write-off workflow aligned across AR invoice and SO invoice entry paths.

### E-Signature Sync

- E-signature sync now handles unavailable envelopes more gracefully.
- Instead of failing the entire processing run, unavailable envelopes can be skipped with a warning.

### Equipment and Employee Calendar Updates

- Updates capitalized cost handling on equipment purchase records.
- Syncs the current employee into the employee labor calendar filter during filter insert/update behavior.
- Refactors employee filter synchronization so the calendar keeps a more reliable current-user schedule context.

## Features Removed or Altered

No package files were removed and no schema changes were detected.

The following behavior was altered:

- PO site defaulting now uses branch/location setup automatically when branch data is available.
- Tax write-off credit memos now use the current business date for the generated credit memo document date.
- E-signature envelope sync treats unavailable envelopes as skipped warning items rather than hard processing failures.
- Equipment capitalized cost calculation behavior was adjusted so purchase amount changes do not overwrite intentional values unnecessarily.
- Employee labor calendar filters now synchronize the current employee more consistently when the filter row is inserted.
