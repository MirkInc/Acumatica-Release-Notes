# MIRK.Customizations Release Notes

Comparison: `2026.02.12` to `2026.04.28`  
Acumatica build: `25.201.0213`

## Features Overview

The 2026.04.28 release is a broad expansion of the MIRK customization package for Acumatica 25R2 build `25.201.0213`. It adds new financial processing, scheduling visibility, document-signing improvements, and deeper equipment profitability tracking.

### DocuSign and E-Sign Improvements

- Adds completed-envelope summary attachments to improve document traceability.
- Adds automated DocuSign field placement so signature fields can be applied consistently.
- Adds support for in-person signing, including host-name tracking.

### Equipment Sale, Purchase, and Profitability Tracking

- Adds more complete equipment financial tracking, including sale details, purchase details, invoice references, paid-in-full status, and customer links.
- Adds financial summaries for rental billing, equipment sale, miscellaneous billing, work-order billing, expenses, and profit/loss.
- Helps teams see a fuller financial picture for each piece of equipment without manually combining data from several places.

### Cash-Basis Payment Application Updates

- Extends the existing cash-basis process to better handle payments after their applications have changed.
- Adds support for surcharge activity so related payment charges can be included in cash-basis conversion.
- Tracks converted adjustments and charge lines to help prevent duplicate cash-basis processing.

### Weekly Work Order Labor Calendar

- Adds a weekly labor calendar so teams can view work-order labor by employee and week.
- Makes scheduling easier by grouping work-order events by employee.
- Provides quick drill-through access from the calendar back to the related work order.

### Purchasing and Part Tracking Improvements

- Adds part number support to purchase orders and PO receipt lines.
- Improves visibility between equipment, manuals, parts, PO lines, and receipt lines.

### Approval and Release Processing Updates

- Improves approval logging with more audit details, including who created an approval log entry, when it was created, and which screen it came from.
- Adds release-processing extensions for AP and AR activity.

## Features Removed or Altered

### Approval Processing Was Reworked

AR and SO invoice approval logic has been changed from a shared base implementation into dedicated implementations. This should make the approval behavior easier to manage by document area, but it is an important change for teams that rely on approval workflows.

### Message Handling Was Consolidated

Several older module-specific message and base files were removed or consolidated into a shared message class. This does not remove user-facing functionality, but it changes how common messages are maintained internally.

### Equipment Screens Were Expanded

Existing equipment screens now show more sale, purchase, note, meter, history, and profitability information. Users may see additional sections and fields on equipment pages compared with the previous package.

### No Package Files Were Removed

The package comparison did not identify any removed package files. The release primarily adds new screens, fields, and supporting logic.

### Functional Comparison

| --- | --- | --- |
