# Acumatica ~ MIRK.Customizations Release Notes

## Features Overview

The 24R1 240819.2 package updates MIRK.Customizations from 24R1 240709 to 24R1 240819.2.

- Updates work order customization behavior used by MIRK teams in Acumatica.
- Refreshes equipment tracking and related Acumatica customization behavior.
- Refreshes compiled customization logic and supporting source files for the package.
- Adds database fields or entities needed by the updated MIRK.Customizations customization behavior.
