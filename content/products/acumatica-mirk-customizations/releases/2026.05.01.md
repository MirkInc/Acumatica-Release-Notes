# Acumatica ~ MIRK.Customizations Release Notes

Comparison: `2026.04.28 to 2026.05.01`  
Build: `25.201.0213`

## Features Overview

The 2026.05.01 package updates MIRK.Customizations from 2026.04.28 to 2026.05.01.

- Fixes a tax-exempt sales order issue where synchronizing tax zones could re-trigger itself and repeatedly update order lines.
- Keeps tax-exempt customer locations aligned to their configured tax zone while avoiding unnecessary line updates.
- Reduces the chance of save/update loops when Rental360 or other order logic also touches sales order tax fields.

### Source Change Summary

#### Modified Source Files

- `MIRK.Customizations/SO/MIRKSOOrderEntryGraphExt_TaxExempt.cs`

#### Code-Level Changes

- Adds a `_syncingTaxExemptLineTaxZones` guard so tax-zone synchronization does not recursively re-enter itself.
- Skips processing when the sales order row is missing or when synchronization is already in progress.
- Updates `OverrideTaxZone` and `TaxZoneID` only when the current values differ from the tax-exempt customer location values.
- Skips sales order lines that are missing inventory/UOM data or already have the target tax zone.
- Wraps line tax-zone updates in a `try/finally` block so the recursion guard is always reset.
